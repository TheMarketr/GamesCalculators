# GamesCalculators Content Quality Rehabilitation

## Pre-edit audit

The audit was completed and reported before source changes began.

- Calculator/tool pages audited: 105
- Substantive generated paragraphs audited: 2,541
- Exact duplicated paragraph groups: 167
- All 105 calculator pages were produced by one game/category prose generator.
- The same independence, mobile, privacy, and free-use FAQ concepts appeared across all 105 tools.
- FAQ questions audited: 842; one privacy question appeared verbatim 105 times.
- Universal prose included “The practical problem is deciding what to do next,” “Change one variable and compare scenarios,” “The calculator is a decision aid,” and “players researching [keyword].”
- Universal headings included “Transparent by design,” “Read the result before you act,” and “Inputs, interpretation and limits.”
- Every tool inherited the same `2026-08-27` timestamp even when the specific formula or dataset had not received a separate editorial review.
- Several reference URLs reused the same catalog and interface with only a filter or default sort changed.

Highest pre-edit route-similarity examples included Grow a Garden Items/Prices/Best Crops, PS99 Pets/Pet Values, MM2 Value List/Trading Values/Knife Values/Godly Values, Adopt Me Neon/Mega Neon, Minecraft Portal/Nether Coordinates, and Fortnite XP/Level/Battle Pass routes.

## Rehabilitation completed

- Replaced the universal supporting-copy generator with 105 explicit structured content records.
- Every record now contains a tool-specific introduction, use cases, input workflow, mechanics, worked example, result interpretation, limitations, and three to five focused FAQs.
- Added relevant reference tables to deterministic formulas and high-priority decision pages.
- Added official Rockstar sources to time-sensitive GTA VI pages and kept unannounced values labeled as scenarios.
- Separated editorial `reviewed` metadata from the old general tool timestamp. Tool pages, hub maintenance logs, homepage review listings, and sitemap `lastmod` values now use the explicit editorial review field.
- Differentiated focused reference routes in their supporting content and documented when the underlying experience still shares a thin catalog.
- Preserved all calculator components, inputs, outputs, local-storage tools, URL paths, and navigation.
- Added `npm run content:check` and a generated readable report.

## Automated result

## Datasets that still need expansion

The content now labels these datasets honestly; the numerical catalogs themselves should still receive dedicated sourcing and expansion work.

- MM2: the local weapon catalog has only nine planning rows and is not a complete knife, Godly, gun, or collection list.
- Pet Simulator 99: the local catalog has only eight pet profiles and does not provide a live RAP or Trading Plaza feed.
- Grow a Garden: the crop/item reference and pet comparison catalog cover only a small subset of current content.
- Blox Fruits: the fruit catalog is useful for demonstrations but needs ongoing rework, availability, permanent/physical, and community-value review.
- Steal a Brainrot: the six-unit catalog needs broader unit, event, mutation, income, and demand coverage.
- Adopt Me: the pet list is a small community reference and does not cover full pet, age, exotic, potion-premium, or event-market variation.
- 99 Nights in the Forest: the role, item, and recipe records are a starter survival reference rather than a complete live-game database.
- Fortnite Weapon Comparison: its six rows are labeled sample archetypes, not a current-season loot-pool dataset.
- Fortnite XP Per Level: it remains user-entered until a verified, season-specific XP-band table is maintained.
- GTA VI pre-release tools: map coordinates, mission payouts, garage prices, activity durations, and multiplayer payout rules remain sample scenarios until post-launch observation is possible.
