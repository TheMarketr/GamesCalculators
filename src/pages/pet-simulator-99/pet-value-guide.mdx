## Decide what you are comparing

Pet power, rarity and trading value describe different things. Power helps with gameplay progress, rarity describes availability, and trading value is a community reference for exchanges. Choose the measure that matches your immediate goal before comparing pets.

## Match the exact version

Different versions of the same pet may not have the same power or value. Confirm the pet name and variant before adding it to an inventory estimate or trade. When a tool offers filters, use them to narrow the list rather than selecting the first similar name.

## Separate individual and inventory totals

An inventory total is useful for a broad snapshot, but it can hide which pets contribute most of the result. Review the largest contributors individually and avoid assuming every pet will exchange at the same rate or on the same schedule.

## Treat hatch odds as probabilities

An odds estimate describes a chance across attempts, not a guaranteed result after a fixed number of hatches. Longer runs can still vary. Plan resources around a range of outcomes instead of one expected attempt count.

## Watch the update date

Pet availability and player demand can shift. The Pet Simulator 99 hub will link its value, trade, odds and comparison tools only as their data and interactions are completed. Each data-dependent page will display its review date so you can judge how current the reference is.
