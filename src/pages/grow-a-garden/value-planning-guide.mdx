## Start with the base crop

A useful estimate begins with the crop itself. Its base value gives you a reference point before weight, growth variants or mutations are applied. Two crops with the same name can finish at very different values, so avoid judging an offer from the crop name alone.

Use the [Grow a Garden Value Calculator](/grow-a-garden/value-calculator/) to select a crop and change one factor at a time. This makes it easier to see which part of the result is doing the most work.

## Treat weight as a scaling input

Weight changes the value of the harvested crop. Compare the entered weight with the reference weight shown by the calculator instead of assuming that every large-looking crop has the same multiplier. Small input differences can become significant after other multipliers are added.

## Stack variants and mutations carefully

Growth variants and mutations can raise the estimate substantially. When several effects are active, verify each one in the interface and in the game before using the total in a trade. A single incorrect selection can distort the result more than a small change in base price.

## Compare offers, not just individual crops

For a multi-item exchange, calculate the complete value on both sides with the [Grow a Garden Trade Calculator](/grow-a-garden/trade-calculator/). Then compare demand and personal usefulness as well as the numerical difference.

Values are planning references, not guaranteed exchange prices. Updates, availability and player preference can move an item away from a previous estimate. Check the displayed update date and use the number as one part of the decision.
