## Track value and income separately

Collection value describes what your selected items are worth in the site's reference data. Income describes what those items generate over time. An item can be important for one measure without leading the other, so keep both totals visible when deciding what to pursue next.

The [Steal a Brainrot Value Calculator](/steal-a-brainrot/value-calculator/) totals quantities, variants and income in one place. Add only items you actually own to get a useful collection snapshot.

## Check the contribution of each item

Large totals can hide the structure of a collection. Review each row and identify which items contribute most of the value and which contribute most of the income. This makes it easier to compare a balanced collection with one that depends heavily on a single item.

## Use consistent mutation assumptions

Apply the correct variant or mutation to each item instead of using one optimistic multiplier across the whole collection. If you are comparing two upgrade paths, change one selection at a time and note the difference in both totals.

## Plan around your goal

For collection growth, prioritize gaps and unique items. For income growth, compare the gain per second with the effort required. For a possible trade, compare the items leaving your collection with the exact versions coming back.

Reference values can change after updates or shifts in availability. Check the page's update date and confirm item details in the game before making a decision.
