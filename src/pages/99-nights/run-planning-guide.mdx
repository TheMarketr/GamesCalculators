## Define the run before collecting supplies

Start with the current night, target night and number of active players. A team preparing for a short push has different needs from one planning a full run, and every extra player changes how quickly shared resources are consumed.

Write down the number of nights remaining. Treat that as the basic planning window for food, fuel and crafting materials.

## Give every player a clear role

Assign simple responsibilities before the run becomes busy. One player can watch fuel, another can gather food, and another can collect materials for the next crafting goal. Roles can rotate, but the team should always know who is checking each critical resource.

## Keep a reserve

Do not plan to reach each night with exactly zero supplies left. A reserve protects the run from slower gathering, missed pickups or a change in priorities. Keep the reserve visible instead of quietly spending it during ordinary progress.

## Review at repeatable checkpoints

Choose regular checkpoints—such as every five or ten nights—to compare remaining supplies with the target. If fuel or food is falling faster than expected, adjust early rather than waiting for an emergency.
