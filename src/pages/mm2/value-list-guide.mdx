## Identify the exact item first

MM2 inventories can contain items with similar names, different categories or different release histories. Confirm the item name and whether it is a knife, gun or another collectible before comparing numbers from a value list.

## Value and demand answer different questions

Reference value gives you a common comparison unit. Demand describes how actively other players may seek the item. A high-value item with weak demand can behave differently in trades from a slightly lower-value item that many players want.

## Use rarity as a filter, not a verdict

Rarity helps narrow a long list, but it does not determine the entire trading picture. Availability, age, item category and current interest can all affect how an item compares with others in the same rarity group.

## Check when the data was updated

A useful value list should show its review date and explain how its values are maintained. If a game update or availability change happened after that date, allow for additional uncertainty until the data is reviewed again.
